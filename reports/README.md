# Reports

Reports are generated from manifests and evidence, not written as unsupported narratives.

Each report must identify:

- repository commit;
- source and configuration hashes;
- dataset and time range;
- engine and adapter versions;
- signals, decisions, order intents, orders, deals, positions and exits;
- gross costs and net results;
- failures, rejected events and remaining limitations.

Suggested subdirectories: `technical/`, `economic/`, `integration/`, `council/`.
